# To-Do List Application Using Python

A simple and interactive To-Do List application developed using Python and Tkinter. This application allows users to manage their daily tasks through a graphical user interface (GUI).

## Features
- Add new tasks.
- View all added tasks.
- Mark tasks as completed.
- Delete tasks.
- User-friendly graphical interface.
- Displays tasks with Pending and Completed status.

## Technologies Used
- Python
- Tkinter
- PyCharm

## Purpose
This project was developed to practice Python programming concepts and learn graphical user interface development using Tkinter.
